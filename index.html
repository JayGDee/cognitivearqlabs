The Engine

Episteme, our deterministic discovery architecture.

Episteme is not a chatbot or a prompt-driven agent. She is a persistent, autonomous cognitive pipeline governed by Deterministic Neuro-Symbolic Orchestration (DNSO).

Persistent

Learns a verified fact today and synthesizes across it tomorrow—no multi-million-dollar retraining cycle.

Autonomous

Explores and synthesizes continuously via a deterministic Arbiter without waiting for human prompts.

Self-Correcting

Traces failed hypotheses to the exact flawed premise (Hinge Analysis) and records negative constraints.

Auditable

Every claim carries confidence scores, independence metrics, and an unbroken chain of source URLs.

Language Layer

The Mouth (Bounded LLM Subroutine)

A local open-weights language model that formats structured outputs into scientific prose. It does not reason, query the web, or decide what is true.

Authority Layer

The Brain: Deterministic Neuro-Symbolic Orchestration

A Python, SQLite, and Z3 constraint-solving pipeline holds all logic, corroboration, and memory writes. Nothing enters the knowledge base without passing it.

Memory Layer

Encrypted, Source-Linked Knowledge (sovereign.db)

Verified multi-source facts are strictly isolated from unverified claims and candidate hypotheses. Predictions are never treated as evidence.
